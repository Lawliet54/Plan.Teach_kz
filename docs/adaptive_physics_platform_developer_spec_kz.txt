АДАПТИВТІ ФИЗИКА ОҚУ ПЛАТФОРМАСЫ
DEVELOPER-ГЕ АРНАЛҒАН ТОЛЫҚ ТЕХНИКАЛЫҚ ЛОГИКА ЖӘНЕ ІСКЕ АСЫРУ ТАЛАПТАРЫ

Нұсқа: 1.0
Жоба бағыты: 7–11 сыныптарға арналған физика пәнінен адаптивті оқу веб-платформасы
Негізгі тіл: қазақ тілі
Мақсат: developer осы құжатты алған кезде адаптивті оқу жүйесінің қандай логикамен жұмыс істеуі керектігін, қандай деректер сақталатынын, қандай API және сервистер қажет екенін, қандай жағдайда оқушыға қандай контент көрсетілетінін толық түсінуі керек.

======================================================================
1. НЕГІЗГІ МАҚСАТ
======================================================================

Платформа барлық оқушыға бірдей оқу жолын ұсынбауы керек.

Жүйе әр оқушы үшін:
- бастапқы білім деңгейін анықтайды;
- әр тақырыптың ішіндегі нақты дағдыларды бөлек бағалайды;
- дұрыс және қате жауаптарды сақтайды;
- қате жауаптың қай дағдыға байланысты екенін анықтайды;
- келесі тапсырманың қиындығын автоматты түрде таңдайды;
- қажет болса қысқа түсіндіру, шешілген мысал және қосымша тапсырмалар береді;
- жоғары нәтиже көрсеткен оқушыны жеңіл тапсырмалардан босатады;
- әлсіз тақырыптарды белгілі бір уақыттан кейін қайталауға қайта ұсынады;
- мұғалімге оқушының нақты әлсіз және мықты тұстарын көрсетеді.

Адаптивтілік тек тақырып бойынша жалпы пайызды көрсету емес.
Негізгі логика: тақырып → дағдылар → тапсырмалар → әрекеттер тарихы → mastery score → келесі ұсыныс.

======================================================================
2. НЕГІЗГІ ТЕРМИНДЕР
======================================================================

Topic:
Оқу тақырыбы. Мысалы: "Тығыздық", "Архимед күші", "Ом заңы".

Skill:
Тақырып ішіндегі нақты меңгерілуі тиіс дағды.
Мысалы:
- тығыздық формуласын білу;
- өлшем бірліктерін түрлендіру;
- формуладан массаны шығару;
- мәтіндік есепті талдау;
- графикті оқу;
- эксперимент нәтижесін түсіндіру.

Prerequisite:
Келесі дағдыны меңгеру үшін алдын ала қажет дағды.
Мысалы:
"см³ → м³ түрлендіру" дағдысын меңгермей Архимед күші есебін толық шешу қиын.

Mastery Score:
Оқушының белгілі бір дағдыны меңгеру көрсеткіші. 0–100 аралығы.

Difficulty:
Тапсырма қиындығы:
- basic
- intermediate
- advanced

Remediation:
Оқушы қате жіберген кезде көрсетілетін түзету оқу жолы:
- қысқа түсіндіру;
- шешілген мысал;
- жеңіл тапсырмалар;
- қайта тексеру.

Checkpoint:
Тақырыпты аяқтау алдында берілетін қорытынды тексеру.

Review Queue:
Ұмытуды болдырмау үшін кейін қайталанатын дағдылар кезегі.

======================================================================
3. ПЛАТФОРМАНЫҢ НЕГІЗГІ ПРИНЦИПТЕРІ
======================================================================

3.1. Бір тақырып бірнеше skill-ге бөлінуі керек.

Мысал: "Тығыздық" тақырыбы.

Skill тізімі:
1) density_definition
   Тығыздық ұғымын түсінеді.

2) density_formula
   ρ = m / V формуласын біледі.

3) formula_transformation
   Формуладан m және V шамаларын шығарады.

4) unit_conversion
   кг, г, м³, см³ бірліктерін түрлендіреді.

5) calculation
   Сандық есеп шығарады.

6) real_life_application
   Өмірлік жағдайға байланысты есепті талдайды.

7) graph_analysis
   Масса–көлем графигін оқиды.

3.2. Әр тапсырма бір немесе бірнеше skill-ді тексеруі керек.

Мысалы:
"Массасы 780 г, көлемі 100 см³ дененің тығыздығын тап."

Тапсырма skill байланысы:
- density_formula
- unit_conversion
- calculation

3.3. Оқушының жалпы бағасы ғана емес, әр skill бойынша жеке masteryScore сақталуы керек.

3.4. Оқушы тақырып бойынша жоғары нәтиже алса да, critical skill төмен болса, келесі деңгейге өтпеуі керек.

Мысал:
- жалпы нәтиже: 92%
- unit_conversion: 48%

Бұл жағдайда жүйе "advanced" деңгейге өткізбейді.
Алдымен unit_conversion бойынша remediation береді.

3.5. Оқушыны қажетсіз контентпен жүктемеу керек.

Егер оқушы диагностикада жоғары деңгей көрсетсе:
- ұзақ базалық теорияны міндетті түрде оқымайды;
- қысқартылған теория көреді;
- күрделі тапсырмаларға бірден өте алады;
- checkpoint арқылы білімін растайды.

3.6. Бір қате жауаптан кейін бірден деңгей төмендетілмейді.

Жүйе соңғы бірнеше әрекетті талдайды:
- соңғы 4–6 тапсырма;
- қатарынан жіберілген қате саны;
- hint қолдану саны;
- тапсырманың қиындығы;
- жауап беру уақыты;
- қайта орындау нәтижесі.

======================================================================
4. РӨЛДЕР ЖӘНЕ ЖАЛПЫ ОҚУ АҒЫНЫ
======================================================================

Рөлдер:
- student
- teacher
- admin

Student:
- алғаш тіркелгенде мұғалім таңдайды;
- диагностикадан өтеді;
- қызығушылықтарын таңдайды;
- жеке оқу жолымен оқиды;
- тапсырма орындайды;
- зертханалық жұмыстар орындайды;
- нәтижелерін және ұсыныстарын көреді;
- AI көмекші қолданады.

Teacher:
- оқушылар тізімін көреді;
- әр оқушының skill mastery нәтижелерін көреді;
- әлсіз тақырыптарды көреді;
- берілген тапсырмаларды тексереді;
- қажет болса қолмен тапсырма тағайындайды;
- адаптивті жүйе ұсыныстарын көреді;
- оқушы прогресін сынып, тақырып және skill бойынша талдайды.

Admin:
- контентті басқарады;
- topic, skill, task, theory, lab материалдарын қосады;
- мұғалімдер мен оқушыларды басқарады;
- контент сапасын тексереді.

Student оқу ағымы:
1) Register
2) Мұғалім таңдау
3) Диагностика
4) Қызығушылық таңдау
5) Dashboard
6) Сынып таңдау
7) Бөлім таңдау
8) Тақырып таңдау
9) Теория немесе қысқартылған теория
10) Практикалық тапсырмалар
11) Checkpoint
12) Нәтиже
13) Adaptive engine шешімі
14) Келесі тақырып / remediation / review

Маңызды:
Onboarding тек бір рет орындалуы керек.
Егер:
- teacher_id бар;
- diagnostic_completed = true;
- onboarding_completed = true;
- interests сақталған;
болса, қайта кіргенде бірден /dashboard ашылады.

5. КОНТЕНТ ҚҰРЫЛЫМЫ
======================================================================

Әр тақырыпта төмендегі контент болуы тиіс:

1) Қысқа теория
2) Толық теория
3) Негізгі анықтамалар
4) Формулалар
5) Өлшем бірліктері
6) Өмірлік мысал
7) Шешілген есеп
8) Жиі кездесетін қателер
9) Basic тапсырмалар
10) Intermediate тапсырмалар
11) Advanced тапсырмалар
12) Графикпен тапсырмалар
13) PISA стиліндегі тапсырмалар
14) Зертханалық жұмыс немесе симуляция
15) Checkpoint
16) Remediation материалдары
17) AI көмекшіге арналған topic context

Әр topic ішінде кемінде 4–7 skill болуы керек.

Әр skill үшін кемінде:
- 1 қысқа түсіндіру;
- 1 толық түсіндіру;
- 1 шешілген мысал;
- 3 basic тапсырма;
- 3 intermediate тапсырма;
- 2 advanced тапсырма;
- 1 қайта тексеру тапсырмасы;
болғаны дұрыс.

======================================================================
6. ДЕРЕКҚОР ҚҰРЫЛЫМЫ
======================================================================

Supabase/PostgreSQL ішінде төмендегі кестелерді жасау керек.

----------------------------------------------------------------------
6.1. profiles
----------------------------------------------------------------------

Мақсаты:
Пайдаланушы профилі және onboarding күйі.

Өрістер:
- id uuid primary key references auth.users(id)
- full_name text
- role text check role in ('student', 'teacher', 'admin')
- teacher_id uuid null references profiles(id)
- grade integer null
- diagnostic_completed boolean default false
- onboarding_completed boolean default false
- diagnostic_level text null check diagnostic_level in ('basic', 'intermediate', 'advanced')
- interests jsonb default '[]'
- created_at timestamptz default now()
- updated_at timestamptz default now()

----------------------------------------------------------------------
6.2. grades
----------------------------------------------------------------------

Өрістер:
- id bigint primary key
- grade_number integer unique
- title text
- is_active boolean default true

Seed:
7, 8, 9, 10, 11

----------------------------------------------------------------------
6.3. sections
----------------------------------------------------------------------

Мақсаты:
Сынып ішіндегі бөлімдер.

Өрістер:
- id uuid primary key
- grade_id bigint references grades(id)
- title text
- slug text unique
- order_index integer
- is_active boolean default true

----------------------------------------------------------------------
6.4. topics
----------------------------------------------------------------------

Мақсаты:

Өрістер:
- id uuid primary key
- section_id uuid references sections(id)
- grade_id bigint references grades(id)
- title text
- slug text unique
- description text
- order_index integer
- estimated_minutes integer
- is_active boolean default true
- has_lab boolean default false
- created_at timestamptz default now()
- updated_at timestamptz default now()

Ескерту:
- Қайталау тақырыптары topic ретінде енгізілмеуі керек.
- ТЖБ topic ретінде енгізілмеуі керек.
- БЖБ негізгі topic атауынан тазартылып, assessment_tag ретінде сақталуы керек.
- Қайталанатын тақырып бірнеше сағатқа берілсе, бір topic ретінде сақталады.
- оқу мақсаттары біріктіріледі.

----------------------------------------------------------------------
6.6. topic_skills
----------------------------------------------------------------------

Мақсаты:
Topic пен skill арасындағы байланыс.

Өрістер:
- id uuid primary key
- topic_id uuid references topics(id)
- skill_id uuid references skills(id)
- weight numeric default 1
- is_required boolean default true
- order_index integer
- unique(topic_id, skill_id)

weight:
Тақырыптық нәтижені есептегенде skill маңыздылығы.
Мысалы:
- негізгі формула: 1.5
- өлшем бірлігі: 1.5
- анықтама: 1.0
- қосымша өмірлік мысал: 0.8

8. SKILL MASTERY ЕСЕПТЕУ ЛОГИКАСЫ
======================================================================

MVP кезеңінде rule-based weighted update қолдану керек.

Мақсат:
Әр жаңа жауаптан кейін skill masteryScore жаңарту.

Негізгі диапазон:
0–100

Бастапқы masteryScore:
- жаңа оқушы, диагностика жоқ: 0
- диагностика basic дұрыс: 40
- диагностика intermediate дұрыс: 65
- диагностика advanced дұрыс: 85
- диагностика қате: алдыңғы мән өзгермейді немесе аздап төмендейді

Әр тапсырмаға difficulty коэффициенті:
- basic = 0.8
- intermediate = 1.0
- advanced = 1.2

Hint коэффициенті:
- hint қолданылмаған = 1.0
- hint қолданылған = 0.7
- бірнеше hint қолданылған = 0.5

Attempt коэффициенті:
- бірінші әрекет = 1.0
- екінші әрекет = 0.85
- үшінші және кейінгі әрекет = 0.7

Skill weight:
task_skills.weight арқылы алынады.

Дұрыс жауап кезінде базалық өсім:
- basic тапсырма: +6
- intermediate тапсырма: +8
- advanced тапсырма: +10

Қате жауап кезінде базалық төмендеу:
- basic тапсырма: -8
- intermediate тапсырма: -7
- advanced тапсырма: -5

Неге advanced қате үшін төмендеу аз:
Күрделі тапсырмада қате жіберу қалыпты.
Ал basic тапсырмада қате жіберу базалық дағды әлсіз екенін көрсетеді.

Формула:

correctDelta =
baseIncrease * difficultyCoefficient * hintCoefficient * attemptCoefficient * skillWeight

wrongDelta =
baseDecrease * skillWeight

Егер жауап дұрыс:
masteryScore = min(100, oldMastery + correctDelta)

Егер жауап қате:
masteryScore = max(0, oldMastery - wrongDelta)

Confidence:
- әр жаңа әрекеттен кейін біртіндеп өседі;
- бір ғана дұрыс жауаптан кейін mastery жоғары болса да confidence төмен болуы мүмкін;
- кемінде 4 әрекет болғанда confidence сенімді деңгейге жетеді.

Ұсынылатын қарапайым формула:
confidence = min(1, totalAttempts / 8)

Қатарынан дұрыс жауап:
- correct болса consecutive_correct + 1
- wrong болса consecutive_correct = 0

Қатарынан қате:
- wrong болса consecutive_wrong + 1
- correct болса consecutive_wrong = 0

Мысал TypeScript логикасы:

type Difficulty = "basic" | "intermediate" | "advanced";

function getDifficultyCoefficient(difficulty: Difficulty): number {
  if (difficulty === "basic") return 0.8;
  if (difficulty === "advanced") return 1.2;
  return 1.0;
}

function getBaseIncrease(difficulty: Difficulty): number {
  if (difficulty === "basic") return 6;
  if (difficulty === "advanced") return 10;
  return 8;
}

function getBaseDecrease(difficulty: Difficulty): number {
  if (difficulty === "basic") return 8;
  if (difficulty === "advanced") return 5;
  return 7;
}

function getHintCoefficient(hintCount: number): number {
  if (hintCount <= 0) return 1;
  if (hintCount === 1) return 0.7;
  return 0.5;
}

function getAttemptCoefficient(attemptNumber: number): number {
  if (attemptNumber <= 1) return 1;
  if (attemptNumber === 2) return 0.85;
  return 0.7;
}

function calculateNewMastery(params: {
  oldMastery: number;
  isCorrect: boolean;
  difficulty: Difficulty;
  hintCount: number;
  attemptNumber: number;
  skillWeight: number;
}): number {
  const {
    oldMastery,
    isCorrect,
    difficulty,
    hintCount,
    attemptNumber,
    skillWeight,
  } = params;

  if (isCorrect) {
    const delta =
      getBaseIncrease(difficulty) *
      getDifficultyCoefficient(difficulty) *
      getHintCoefficient(hintCount) *
      getAttemptCoefficient(attemptNumber) *
      skillWeight;

    return Math.min(100, Math.round((oldMastery + delta) * 100) / 100);
  }

  const delta = getBaseDecrease(difficulty) * skillWeight;
  return Math.max(0, Math.round((oldMastery - delta) * 100) / 100);
}

9. TOPIC MASTERY ЕСЕПТЕУ
======================================================================

Topic masteryScore барлық skill-дердің салмақталған орташа мәнімен есептелуі керек.

Формула:

topicMastery =
sum(skillMastery * topicSkillWeight)
/
sum(topicSkillWeight)

Мысал:
- concept = 90, weight = 1
- formula = 80, weight = 1.5
- unit_conversion = 50, weight = 1.5
- calculation = 75, weight = 1.5
- graph_analysis = 70, weight = 1

topicMastery =
(90*1 + 80*1.5 + 50*1.5 + 75*1.5 + 70*1)
/
(1 + 1.5 + 1.5 + 1.5 + 1)

Қорытынды нәтиже тек topicMastery емес.

Checkpoint, practice, lab және applied task нәтижелерін бөлек сақтау керек.

Ұсынылатын формула:
finalTopicScore =
checkpointScore * 0.50 +
practiceScore * 0.25 +
laboratoryScore * 0.15 +
appliedTaskScore * 0.10

Егер тақырыпта lab жоқ болса:
finalTopicScore =
checkpointScore * 0.60 +
practiceScore * 0.30 +
appliedTaskScore * 0.10

Advance шарты:
- finalTopicScore >= 90
- барлық required skill masteryScore >= 70
- барлық critical skill masteryScore >= 80
- checkpoint тапсырмалары орындалған
- confidence жеткілікті: орташа confidence >= 0.5

Егер жалпы пайыз жоғары, бірақ critical skill төмен болса:
- advanced деңгей ашылмайды;
- remediation көрсетіледі;
- skill review queue қосылады.

Client ішінде негізгі шешім логикасын сақтамау керек.
Себебі frontend өзгертілуі мүмкін және нәтижені қолдан өзгерту қаупі бар.

AdaptiveAction:

- open_next_topic
- continue_same_level

- return_to_prerequisite
- schedule_review
- teacher_attention_required

Шешім қабылдау басымдық реті:

1) Егер prerequisite skill < 50:
   return_to_prerequisite

2) Егер critical skill < 60:
   show_remediation

3) Егер consecutive_wrong >= 3:
   show_remediation

4) Егер бір skill бойынша 5 әрекеттен кейін masteryScore < 40:
   teacher_attention_required

5) Егер topic final score >= 90 және critical skill >= 80:

6) Егер topic final score 70–89:

7) Егер topic final score < 70:

8) Егер тақырып аяқталғанына 3–14 күн өтсе:
   schedule_review

TypeScript псевдокод:

type AdaptiveAction =
  | "advance_level"
  | "open_next_topic"
  | "continue_same_level"
  | "show_remediation"
  | "return_to_prerequisite"
  | "schedule_review"
  | "teacher_attention_required";

function chooseAdaptiveAction(params: {
  finalTopicScore: number;
  criticalSkillMinScore: number;
  prerequisiteMinScore: number;
  totalAttemptsForWeakSkill: number;
  weakSkillScore: number;
  consecutiveWrong: number;
  recentAttemptsCount: number;
}): AdaptiveAction {
  const {
    finalTopicScore,
    criticalSkillMinScore,
    prerequisiteMinScore,
    totalAttemptsForWeakSkill,
    weakSkillScore,
    consecutiveWrong,
    recentAttemptsCount,
  } = params;

  if (prerequisiteMinScore < 50) {
    return "return_to_prerequisite";
  }

  if (criticalSkillMinScore < 60) {
    return "show_remediation";
  }

  if (consecutiveWrong >= 3) {
    return "show_remediation";
  }

  if (totalAttemptsForWeakSkill >= 5 && weakSkillScore < 40) {
    return "teacher_attention_required";
  }

  if (recentAttemptsCount < 4) {
    return "continue_same_level";
  }

  if (finalTopicScore >= 90 && criticalSkillMinScore >= 80) {
    return "advance_level";
  }

  if (finalTopicScore >= 70) {
    return "open_next_topic";
  }

  return "show_remediation";
}

async function selectNextTask(params: {

function calculateNextReviewDate(masteryScore: number, afterRemediation: boolean): Date {
  const now = new Date();

  if (afterRemediation) {
    now.setDate(now.getDate() + 2);
    return now;
  }

  if (masteryScore >= 90) {
    now.setDate(now.getDate() + 14);
    return now;
  }

  if (masteryScore >= 80) {
    now.setDate(now.getDate() + 7);
    return now;
  }

  now.setDate(now.getDate() + 3);
  return now;
}

3) Task бар-жоғын тексеру.

12) topic mastery қайта есептеу.
13) critical skill және prerequisite skill тексеру.
14) adaptive action таңдау.
15) adaptive_recommendations кестесіне жазу.
16) қажет болса review queue қосу.
17) қажет болса remediation ашу.
18) learning_events ішіне task_submitted жазу.
19) Client-ке қауіпсіз response қайтару.

28. ACCEPTANCE CRITERIA
======================================================================

Жүйе дайын деп есептелуі үшін төмендегі талаптар орындалуы керек:

1) Жаңа student тіркелгенде onboarding бір рет ашылады.
2) Диагностика аяқталғаннан кейін diagnostic_level сақталады.
3) Әр topic кемінде бір skill-мен байланысқан.
4) Әр task кемінде бір skill-мен байланысқан.
5) Student task тапсырған сайын жаңа attempt сақталады.
6) Жауаптан кейін skill mastery жаңарады.
7) Topic mastery қайта есептеледі.
8) 90–100% нәтиже және critical skill >= 80 болса деңгей өседі немесе келесі topic ашылады.
9) 70–89% болса келесі topic ашылады, review queue қосылады.
10) 70%-дан төмен болса remediation ашылады.
11) Critical skill төмен болса, жалпы пайыз жоғары болса да advanced ашылмайды.
12) Қатарынан 3 қате жауаптан кейін remediation беріледі.
13) Prerequisite skill < 50 болса, алдыңғы skill қайталауға беріледі.
14) Бір task соңғы 10 әрекет ішінде қайта берілмейді.
15) Teacher әр оқушының әлсіз skill тізімін көреді.
16) Teacher attention required оқушылар бөлек көрсетіледі.
17) Lab нәтижесі topic score-ға әсер етеді.
18) Review queue белгіленген күні dashboard-та көрсетіледі.
19) Frontend correct_answer мәнін алмайды.
20) Student басқа student деректерін көре алмайды.
21) Teacher тек өз student деректерін көреді.
22) AI жұмыс істемесе де негізгі оқу ағымы тоқтамайды.
23) UI ішінде developer-ге арналған code немесе slug көрсетілмейді.
24) Барлық интерфейс мәтіні қазақ тілінде болады.
25) Mobile және desktop нұсқада негізгі оқу ағыны толық жұмыс істейді.
